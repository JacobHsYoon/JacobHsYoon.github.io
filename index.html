Featured Project

STM32 Actuator Controller

Built a robotic gripper actuator controller using STM32 with UART command input, PWM motor control, and encoder feedback for repeatable position-based motion.

  • Redesigned the system from open-loop timing control to closed-loop encoder feedback
  • Reduced position variation from about 17% to roughly +/-2%
  • Implemented low-level control logic in C with home reference and software limits

PCB Design

DRV8833 Motor Driver PCB

Designed a DRV8833-based motor driver PCB for an STM32-controlled actuator system with separated 6V motor and 3.3V logic domains.

  • Placed bulk and local decoupling capacitors for stable drive behavior
  • Separated power and signal routing with wide current traces and stitched grounds
  • Assembled and validated bidirectional motor control with the actuator controller

System Integration

Mars Rover PCB

Developed a temperature sensing PCB for rover system integration using TMP1075 over I2C, 3.3V regulation, and hardware validation through bench testing.

  • Separated 5V input and 3.3V regulation for cleaner power delivery
  • Used pull-ups and short signal paths to improve I2C reliability
  • Fabricated and tested the board to confirm stable sensor readings

Let's Power Lego City

Created an interactive hardware-software system using Arduino control logic, mechanical components, and MATLAB visualization to respond to circuit state changes.

  • Designed physical components with AutoCAD and SolidWorks
