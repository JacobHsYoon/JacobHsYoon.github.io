Project Detail

Mars Rover PCB

A temperature sensing PCB designed for rover system integration, built around 5V input, 3.3V regulation, TMP1075 I2C communication, and hardware validation through fabrication and testing.

Back to Projects

Goal

Design a PCB for temperature sensing and system integration that could interface cleanly with a larger rover platform.

System

  • 5V input with onboard 3.3V regulation
  • TMP1075 temperature sensor over I2C
  • MCU-facing interface for data use in the rover system
  • LED and connector integration for system-level usability

Overview

This project focused on creating a practical sensor board for rover integration rather than only a standalone electronics exercise. The design needed stable power regulation, reliable I2C communication, and a layout that made sense as part of a larger physical system.

The board included both sensing and interface elements, which made component placement and system organization important from the beginning of the design process.

Portfolio Slides

Design Strategy

  • Separated 5V input and 3.3V power domains for cleaner regulation
  • Placed local decoupling near the regulator and sensor
  • Added pull-up resistors for stable I2C communication
  • Kept SDA and SCL routing short and organized
  • Used ground pours and functional block placement for cleaner layout

The layout was shaped around signal integrity and system readability. That meant keeping the communication path clean, maintaining sensible spacing around power components, and grouping parts according to their function in the rover system.

Hardware Validation

Fabrication

  • Fabricated and assembled the PCB
  • Checked component placement and power behavior during bring-up
  • Verified that the board could operate as intended after assembly

Testing

  • Verified I2C communication with TMP1075
  • Confirmed stable temperature sensor readings
  • Validated that the board functioned as a usable rover sensing module

What I Learned

  • Reliable communication depends on both schematic choices and layout discipline
  • Sensor boards benefit from thinking early about how they will connect into a full system
  • Validation after fabrication is essential for confirming that the design assumptions hold in hardware
