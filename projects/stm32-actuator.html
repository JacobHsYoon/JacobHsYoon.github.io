Project Detail

STM32 Actuator Controller

A robotic gripper actuator controller built around STM32, redesigned from simple time-based control toward repeatable encoder-based position control.

Demo Video Code Back to Projects

Goal

Design a controllable robotic gripper actuator using STM32 with real-time command input and position-based control.

Key Features

  • UART command interface with 1-byte interrupt handling
  • PWM motor control with encoder feedback
  • Home reference and software limits
  • Closed-loop redesign for repeatable motion

Overview

This project started with a time-based open-loop motor control approach. In testing, the same command duration produced different gripper motion because of load and friction, which made the system unreliable for repeatable actuation.

I then redesigned the controller around encoder feedback so the system could compare target position against current position and converge more consistently to the desired state.

Engineering Process

  • Initial system used time-based open-loop control for simplicity
  • Repeated tests showed about 597 to 711 encoder counts for the same 500 ms command
  • This represented roughly 17% variation and showed the limits of open-loop control
  • The system was redesigned to use encoder counts as feedback for target-based motion

Debugging and Decision

Open-loop Result

  • Simple implementation and fast early testing
  • Position changed depending on load and friction
  • Could not guarantee consistent motion

Closed-loop Result

  • Target position around +/-2100 to +/-2200 counts
  • Typical error around +/-20 to +/-40 counts
  • Worst-case error around +/-100 counts

Overall, the redesign improved positioning consistency by roughly 4 to 5 times and made the actuator much more reliable for future robotics use.

What I Learned

  • Real hardware behavior often reveals issues that simple control logic hides
  • Feedback is essential when actuator behavior changes with load
  • Measured redesign decisions are often more effective than forcing an initial architecture
